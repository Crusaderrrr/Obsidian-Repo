1. **Too many arguments**
	the less arguments a function has, the better. Best, when no arguments at all
2. **Flags in arguments**
	Logical flags in function arguments mean that it does more than one thing, which is bad
3. **Dead functions**
	If a function is not called anywhere in the code, it is better to remove it.
	if someone needs it, the tools of version control will help recuperate it
