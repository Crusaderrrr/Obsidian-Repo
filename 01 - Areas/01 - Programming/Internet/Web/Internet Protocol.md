There are two current versions of IP addresses:
- **IPv4** - 4 8-bit digits separated with `.` (e.g. `192.168.1.2`)
- **IPv6** - 8 16-bit digits separated with `:` (e.g. `2001:0db8:0a0b:12f0:0000:0000:0000:0001`) 

*IPv6 is used by 50%* of all the internet traffic.

There are two types of IPv4 addresses: 
- **Static** - used by big sites, like google
- **Dynamic** - used by visitors, is not permanent

Also, IPv4 can be:
- **Internal**  - given by the provider for the inner network
- **External** - also given by the provider for the global network
So, if there are *two identical addresses*, they can be distinguished, because *port is added* to the address.

It is not possible to find someone by the IP, it is just a myth. =)
