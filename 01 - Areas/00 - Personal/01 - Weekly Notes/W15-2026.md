# D8AForce CI/CD — Improvement Suggestions

## 1. Enable Test Execution

Backend tests are deliberately skipped (`./gradlew build -x test`) and frontend has no test step at all. Tests should run as a quality gate **before** the Docker image is built, so a failing test blocks deployment entirely.

## 2. Add Test Reporting

Neither pipeline captures or reports test results. Adding a `reports` block to each buildspec would surface pass/fail results in a dedicated CodeBuild Reports tab, making build health visible without digging through raw logs.

## 3. Replace `npm install` with `npm ci`

`npm install` can silently mutate `package-lock.json` and introduce version drift between builds. `npm ci` is the correct command for CI environments — it's faster, reproducible, and strict.

## 4. Client related pipelines

In my opinion should stay unchanged, because there is an explicit stage of approvement (supposedly by the client), but testing could also be added there along with tests output (reporting).
